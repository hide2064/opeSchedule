案B — parent_project_id FK（推奨） ID参照で確実DBマイグレーション必要

DBに parent_project_id INTEGER FK → projects.id を追加。
ProjectModal の編集画面に「親プロジェクト」ドロップダウンを追加し、選択で親子関係を設定。
ツリー表示は案Aと同じ見た目。名前変更しても関係が切れない。既存の base_project テキスト欄は説明として継続利用。

案Aと画面表示は同じ。唯一の違いは「親子関係の設定方法」のみ（テキスト入力 vs ドロップダウン選択）。

案C — model_name グループ化 + base_project ツリー DB変更なしmodel_nameが空のプロジェクトは別扱い

同じ model_name のプロジェクトをアコーディオングループで表示。グループヘッダーをクリックで折りたたみ可能。
グループ内では base_project の有無によりルート/子を分類して階層表示。
model_name が未設定のプロジェクトは「その他」グループにまとめる。

レイアウトが現行と大きく変わる。model_nameを使っていないプロジェクトは「その他」に集約される。
