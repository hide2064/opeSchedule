## 1. はじめに

**opeSchedule** は Web ベースの開発スケジュール管理ツールです。  
ガントチャート形式でプロジェクトのタスクを可視化・管理し、チームや顧客への進捗報告に活用できます。

### 主な機能

| 機能 | 説明 |
|------|------|
| ガントチャート | 大項目・中項目・小項目の3階層でタスクを表示 |
| タスク管理 | 追加・編集・複製・削除、ドラッグで日程変更 |
| 担当者管理 | プロジェクトメンバーを登録し、タスクに担当者を設定 |
| 遅延アラート | 期限超過タスクを赤でハイライト、⚠ マーク表示 |
| 今日ライン | 今日の日付位置に赤い縦線を表示 |
| タスク検索 | タスク名・大中項目・メモをキーワード検索 |
| 担当者フィルター | 指定した担当者のタスクのみを表示 |
| 大項目フィルター | ガントチャート上で特定の大項目を非表示 |
| 日程一括シフト | 全タスクの日程をN日まとめて後ろ倒し・前倒し |
| 依存関係 | タスク間の依存を設定し、クリティカルパスを可視化 |
| バーンダウンチャート | 計画 vs 実績の残タスク数をグラフで確認 |
| バージョン管理 | 手動スナップショットで変更履歴を管理 |
| ベースライン比較 | スナップショットと現在のタスクをガントチャート上で重ねて比較 |
| 付箋 | ガントチャート上にフリーテキストのメモを配置 |
| テンプレート | プロジェクトのタスク構成をテンプレートとして保存・再利用 |
| 比較表示 | 複数プロジェクトを横並びで確認 |
| 親子プロジェクト | 親プロジェクト配下の子プロジェクトを統合表示 |
| Import/Export | JSON・CSV 形式でデータを入出力 |
| 一括 Export/Import | 全プロジェクトをまとめてバックアップ・リストア |
| 印刷 / PDF | ブラウザの印刷機能でガントチャートを出力 |
| メール通知 | 週次サマリーを指定アドレスへ自動送信 |

## 2. 起動方法

### Docker（通常起動）

PowerShell でプロジェクトルートから実行します。

```powershell
.\start.ps1
```

起動後、ブラウザで **http://localhost:8000** にアクセスします。

> `.\start.ps1` は内部で `docker compose up --build` を実行し、フロントエンドのビルドとサーバー起動を一括で行います。

### Docker（デバッグ起動）

VSCode でバックエンドをデバッグする場合:

```powershell
.\start_debug.ps1
```

起動後、VSCode で「FastAPI: Attach to Docker (port 5678)」を選択してアタッチします。

### コンテナ停止

```powershell
docker compose down
```

> SQLite DB は Docker named volume（`db_data`）に保存されているため、コンテナを停止・削除してもデータは残ります。

### ログ確認

```powershell
docker compose logs -f
```

## 3. Top 画面の操作

`http://localhost:8000/` がトップ画面です。

### 3.1 プロジェクト一覧

画面左の「比較表示」「大項目フィルター」サイドバーと、右側のプロジェクト一覧で構成されます。

| 列 | 内容 |
|----|------|
| 色ドット | プロジェクトカラー |
| モデル名 / プロジェクト名 | クリックでスケジュール画面へ移動 |
| ステータス | 未開始 / 作業中 / 中断 / 終了 |
| 客先 | 客先名チップ |
| ベース | ベースプロジェクトチップ |
| バージョン | 最新スナップショット番号（例: v3） |
| 最終更新 | 最後に変更した日時 |
| 操作 | Edit / Del ボタン |

### 3.2 プロジェクト作成

1. 画面右上の **「+ New Project」** をクリック
2. 以下の項目を入力します

| 項目 | 説明 |
|------|------|
| モデル名 | 機種・製品名など（省略可）。ガントヘッダーにプロジェクト名の前に表示 |
| プロジェクト名 | 必須 |
| 説明 | 概要テキスト（省略可） |
| カラー | プロジェクトの識別色 |
| ステータス | 未開始 / 作業中 / 中断 / 終了 |
| 客先 | 客先名（省略可） |
| ベースプロジェクト | 参照元プロジェクト名（省略可） |
| 親プロジェクト | このプロジェクトを配下に持つ親プロジェクト（省略可）|

3. **「Save」** をクリック

#### プロジェクトコピー

既存プロジェクトのタスク構成をコピーして新規作成できます。

1. 「+ New Project」→ 「コピー元プロジェクト」で複製元を選択
2. 「アンカー日付タイプ」（開始日基準 or 終了日基準）と日付を指定
3. タスクの日程が指定アンカーに合わせてシフトされてコピーされます

### 3.3 プロジェクト編集

プロジェクト行の **「Edit」** ボタンをクリックして編集モーダルを開きます。

> **アーカイブルール:** project_status を「中断」または「終了」に設定すると自動的にアーカイブされ、一覧から非表示になります。「アーカイブ済みを表示」チェックボックスで表示を切り替えられます。

### 3.4 プロジェクト削除

プロジェクト行の **「Del」** ボタンをクリックします。  
確認ダイアログで OK を選択すると、プロジェクトとすべてのタスクが削除されます。

### 3.5 Global Config 設定

「Global Config」タブで以下の設定を変更できます。

#### 表示設定

| 設定項目 | 説明 |
|---------|------|
| 週の開始曜日 | Mon / Sun / Sat |
| デフォルト表示 | Day / Week / Month / Quarter |
| テーマ | Light / Dark |
| 週末をハイライト | ガントチャートの土日を背景色で区別 |
| 今日に自動スクロール | スケジュール画面を開いたとき今日位置にスクロール |

#### メール通知設定

週次サマリーを指定したメールアドレスへ自動送信できます。

| 設定項目 | 説明 |
|---------|------|
| 週次サマリーメールを送信する | 有効にすると指定時刻に送信 |
| 送信先メールアドレス | カンマ区切りまたは改行区切りで複数指定可 |
| 送信時刻 | 毎日の自動送信時刻（HH:MM） |

## 4. Schedule 画面の操作

プロジェクト名をクリックすると `/schedule?project=<id>` に遷移します。

### 4.1 ガントチャートの見方

```
┌──────────┬──────────┬──────────────╥──────────────────────────────┐
│ 大項目   │ 中項目   │ 小項目       ║  日付ヘッダー                 │
├──────────┼──────────┼──────────────╫──────────────────────────────┤
│          │          │ 市場調査     ║  ████████  (通常バー)         │
│          │          │ 設計完了 ⚠  ║  ████████  (遅延=赤バー)      │
│ Phase1   │ 調査     │ 設計レビュー ║  ████████  (完了=グレーバー)  │
│          │          │ キックオフ ◆ ║     ◆     (マイルストーン)   │
└──────────┴──────────┴──────────────╨──────────────────────────────┘
                                              ↑
                                       今日ライン（赤い縦線）
```

#### バー色の意味

| 色 | 状態 |
|----|------|
| 青（デフォルト）| 通常タスク（進行中・未開始） |
| **赤** | 期限超過（end_date < 今日 かつ 進捗 < 100%） |
| グレー | 完了（進捗 = 100%） |
| プロジェクト設定色 | カラーが設定されたタスク |

> 期限超過タスクは左ペインの小項目にも **⚠** マークが表示されます。

#### 今日ライン

現在の日付位置に **赤い縦線** が常時表示されます。チャート範囲外の場合は非表示です。

### 4.2 表示モード切り替え

ヘッダーの **[Day] [Week] [Month] [Quarter]** ボタンで表示密度を変更します。

| モード | pxPerDay | 適した期間 |
|--------|----------|-----------|
| Day    | 40px     | 1〜2ヶ月 |
| Week   | 8px      | 3〜6ヶ月 |
| Month  | 2.5px    | 1〜2年 |
| Quarter| 0.8px    | 3〜5年 |

### 4.3 タスク追加

1. **「+ Add Task」** ボタンをクリック
2. 大項目・中項目・小項目（タスク名）を入力
3. 開始日・終了日・種別（タスク / マイルストーン）・進捗率を設定
4. **「Add」** をクリック

### 4.4 タスク編集

- **小項目名クリック**（左ペイン）または**タスクバークリック**（右ペイン）で詳細パネルを開く
- 各フィールドを編集後 **「Save」** をクリック
- 依存関係は「依存するタスク」チェックボックスで設定

### 4.5 タスク複製

1. タスク詳細パネルを開く
2. **「複製」** ボタンをクリック
3. 同じ大項目・中項目内に名前に「(コピー)」が付いたタスクが +1 日ずれて作成されます

### 4.6 タスク削除

タスク詳細パネルの **「Delete」** ボタンをクリックします。  
確認ダイアログで OK を選択すると削除されます。

### 4.7 ドラッグによる日程変更

タスクバーを左右にドラッグして日程を変更します。  
リリース後に API が呼ばれて DB に保存されます。

> マイルストーン（◆）はドラッグできません。詳細パネルから日付を変更してください。

バーの左端・右端のハンドルをドラッグすると、開始日・終了日だけを個別に調整できます。

### 4.8 タスク検索

ヘッダーの **「タスクを検索...」** 入力欄にキーワードを入力すると、  
タスク名・大項目・中項目・メモにマッチするタスクのみが表示されます。  
入力欄をクリアすると全タスクが再表示されます。

### 4.9 担当者管理

#### メンバー登録

タスク詳細パネルの「担当者」ドロップダウンを使うには、先にプロジェクトのメンバーを登録します。  
メンバー管理は Schedule 画面のヘッダー右のメニューまたは別途管理画面から操作します。

#### 担当者フィルター

ヘッダーの担当者ドロップダウンから担当者を選択すると、そのメンバーのタスクのみが表示されます。  
「全員」を選択するとフィルターを解除します。

### 4.10 大項目フィルター（チャート内）

ヘッダーの **「🗂 大項目 ▾」** ボタンをクリックするとドロップダウンが表示されます。

- 各大項目のチェックを外すとチャート上で非表示になります
- **「全表示」** / **「全非表示」** ボタンで一括切り替えができます
- フィルター適用中はボタンに `n/m` の件数バッジが表示されます

### 4.11 依存関係とクリティカルパス

**依存関係:** タスク詳細パネルの「依存するタスク」セクションで設定します。  
後続タスクの開始は先行タスクの終了後になることを示します。

**クリティカルパス:** 先行タスクの終了日と後続タスクの開始日のスラック（余裕）が 0 以下の連鎖を赤くハイライトします。  
比較モード・履歴モードではクリティカルパスは非表示です。

### 4.12 付箋（アノテーション）

ガントチャートエリア（タスクバー以外の場所）を **ダブルクリック** するとテキスト入力欄が表示されます。

- **Enter** または入力欄外クリックで保存
- **Esc** でキャンセル
- 付箋の **✕** ボタンで削除
- X 位置は日付基準で保存されるため、表示モード切り替え後も正しく表示されます

> 比較モード・履歴モードでは付箋の追加はできません。

### 4.13 Menu（☰）からの操作

ヘッダーの **「☰ Menu ▾」** ボタンをクリックすると以下の操作メニューが表示されます。

| メニュー項目 | 動作 |
|------------|------|
| 📄 JSON 出力 | プロジェクトを JSON ファイルとしてダウンロード |
| 📊 CSV 出力 | タスクデータを CSV ファイルとしてダウンロード |
| 🖨 印刷 | ブラウザの印刷ダイアログを開く |
| 📋 週報 | 週次レポートモーダルを表示 |
| 📉 バーンダウンチャート | バーンダウンチャートを表示 |
| 📊 ベースライン比較 | ベースラインスナップショットと現在の差分を表示（設定済み時のみ） |
| 📅 日程シフト... | 全タスクの日程を一括シフトするダイアログを開く |
| 📋 履歴 | バージョン管理・履歴パネルを開く |
| 💾 テンプレートとして保存... | 現在のタスク構成をテンプレートに保存 |

### 4.14 日程一括シフト

スケジュール全体を後ろ倒し・前倒しする場合に使います。

1. **「☰ Menu」** → **「📅 日程シフト...」** をクリック
2. 日数を入力（正の値: 後ろ倒し、負の値: 前倒し）
3. **「シフト実行」** をクリック
4. 全タスクの開始日・終了日が指定日数だけ移動します

> 例: `7` を入力すると全タスクが7日後ろ倒しになります。`-3` で3日前倒しになります。

### 4.15 バーンダウンチャート

**「☰ Menu」** → **「📉 バーンダウンチャート」** をクリックするとモーダルが表示されます。

| ライン | 内容 |
|-------|------|
| 計画ライン | プロジェクト開始〜終了までタスクが均一に完了する理想曲線 |
| 実績ライン | 各タスクの進捗率と終了日に基づく実際の残タスク推移 |

X 軸はプロジェクト期間、Y 軸は残タスク数です。

### 4.16 バージョン管理・履歴

#### バージョンUP

1. **「☰ Menu」** → **「📋 履歴」** をクリックして履歴パネルを開く
2. 「バージョン名」を入力（例: "設計完了", "リリース v1.0"）
3. **「⬆ バージョンUP」** をクリック
4. 現在の全タスクがスナップショットとして保存されます

> 「📋 履歴」のバッジ数は前回バージョンUP以降の変更件数を示します。

#### 過去バージョンの閲覧

履歴パネルのバージョン一覧をクリックすると、その時点のタスク内容を**読み取り専用**で表示します。  
ヘッダーに「📜 履歴表示: v{n} — {ラベル}（読み取り専用）」バナーが表示されます。  
**「現在に戻る」** ボタンで現在の編集状態に戻ります。

#### ベースライン比較

特定のスナップショットをベースラインに設定すると、ガントチャート上で現在タスクとの差分を重ねて表示できます。

1. 履歴パネルでスナップショットの **「ベースラインに設定」** をクリック
2. **「☰ Menu」** → **「📊 ベースライン比較: ON」** をクリックして表示を有効化
3. ガントチャートにベースライン（半透明バー）が重ねて表示されます

### 4.17 テンプレート

#### テンプレートとして保存

1. **「☰ Menu」** → **「💾 テンプレートとして保存...」** をクリック
2. テンプレート名・説明を入力
3. **「保存」** をクリック

#### テンプレートの適用

プロジェクト作成モーダルから「テンプレートから作成」オプションでテンプレートを適用できます。  
基準日を指定するとタスクの日程がシフトされて配置されます。

### 4.18 Export / Import（単体プロジェクト）

#### エクスポート

**「☰ Menu」** → **「📄 JSON 出力」** または **「📊 CSV 出力」** をクリックしてダウンロードします。

| 形式 | 内容 |
|------|------|
| JSON | プロジェクトメタデータ + タスク + 依存関係（完全バックアップ） |
| CSV | タスクデータのみ（Excel 等での確認・編集向け） |

#### インポート

Top 画面 → プロジェクト一覧の **「Import」** ボタン → JSON/CSV ファイルを選択します。  
新規プロジェクトとして作成されます。

### 4.19 印刷 / PDF 出力

**「☰ Menu」** → **「🖨 印刷」** をクリックします。  
ブラウザの印刷ダイアログが開き、「PDF として保存」を選択することでガントチャートを PDF 形式で保存できます。

> 印刷時はツールバー・ヘッダーなど UI コントロールは自動的に非表示になります。  
> A3 横向きが標準設定です。ブラウザの印刷設定で変更できます。

### 4.20 週次レポート

**「☰ Menu」** → **「📋 週報」** をクリックすると、現在のプロジェクトの週次サマリーレポートがモーダルで表示されます。

**レポートの内容:**

| セクション | 内容 |
|-----------|------|
| ✅ 今週完了 | 今週中（月〜日）に `end_date` が含まれ、進捗 100% のタスク |
| ⚠ 遅延中 | `end_date` が今日より前で未完了のタスク・マイルストーン |
| 📅 来週完了予定 | 来週中に `end_date` が含まれる未完了タスク |
| ◆ 今後3ヶ月マイルストーン | 今日から90日以内のマイルストーン（日付順） |

**出力方法:**

| ボタン | 動作 |
|-------|------|
| 📋 Markdown コピー | レポートを Markdown 形式でクリップボードにコピー。Slack・Notion・メール等に貼り付け可能 |
| 🖨 印刷 | ブラウザの印刷ダイアログを開く。レポート本体のみ印刷される |

> 「今週」の起点は Global Config の「週の開始曜日」（月曜/日曜/土曜）に従います。

## 5. 比較表示・親子プロジェクト・大項目フィルター

Top 画面左のサイドバーから操作します。

### 5.1 比較表示

複数プロジェクトのガントチャートを横並びで確認できます。

1. 左サイドバーの **「📊 比較表示」** セクションを展開
2. 比較したいプロジェクトにチェックを入れる（2件以上）
3. **「まとめて表示」** ボタンをクリック

> URL: `/schedule?projects=1,2,3`  
> 比較モードでは編集・タスク追加・履歴などの操作はできません（読み取り専用）。

### 5.2 親子プロジェクト表示

親プロジェクトとその配下の子プロジェクトのタスクを1画面に統合して表示・編集できます。

1. プロジェクト作成時に「親プロジェクト」を設定して子プロジェクトを作成
2. Top 画面のプロジェクト一覧で親プロジェクト名の **「📂」** アイコンをクリック  
   または URL に `/schedule?parent=<親プロジェクトID>` でアクセス

> 親子モードでは全タスクの編集・ドラッグ操作・タスク追加が可能です。  
> 付箋は親プロジェクトに紐付けて保存されます。

### 5.3 大項目フィルター（横断表示）

全プロジェクト横断で特定の大項目のみを表示します。

1. 左サイドバーの **「大項目フィルター」** セクションを展開
2. フィルターしたい大項目にチェックを入れる
3. 表示したいプロジェクトにチェックを入れる
4. **「フィルター表示」** ボタンをクリック

> ガントチャート画面内の **「🗂 大項目」** ボタンは、現在開いているチャートの大項目を個別に表示/非表示にするものです（横断フィルターとは別機能）。

## 6. マスター操作（一括 Export/Import）

Top 画面 → **「Global Config」** タブ → 最下部の **「マスター操作」** セクションで操作します。

### 6.1 全プロジェクトをエクスポート

**「全プロジェクトをエクスポート (JSON)」** ボタンをクリックします。  
`opeschedule_all_YYYYMMDD.json` という名前でファイルがダウンロードされます。

このファイルには全プロジェクトのメタデータとタスクが含まれます（`version: "2.0"`）。  
バックアップや別環境への移行に使用できます。

### 6.2 一括インポート

1. **「同名プロジェクトはスキップ」** チェックボックスで動作を選択
   - オフ（デフォルト）: 常に新規プロジェクトとして作成
   - オン: 同名プロジェクトが既に存在する場合はスキップ
2. **「一括インポート (JSON)」** ボタンをクリック
3. エクスポートしたファイル（`opeschedule_all_*.json`）を選択
4. 完了するとトーストで結果が表示されます（例: "インポート完了: 5件作成, 1件スキップ"）

> **注意:** 一括インポートは `version: "2.0"` の bulk_export 形式のみ対応しています。  
> 単一プロジェクトの JSON ファイル（`version: "1.0"`）は Top 画面の **「Import」** ボタンからインポートしてください。

### 6.3 ファイルサイズ制限

| 操作 | 上限 |
|------|------|
| 単一プロジェクト Import | 10 MB |
| 一括 Import | 50 MB |

## 7. トラブルシューティング

### Q: アプリが起動しない

- Docker Desktop が起動しているか確認してください
- `docker compose logs -f` でエラーメッセージを確認してください
- `.\start.ps1` を再実行してイメージを再ビルドしてください

### Q: データが消えた

- SQLite DB は Docker named volume（`db_data`）に保存されています
- `docker compose down` ではデータは削除されません
- `docker compose down -v` を実行するとボリュームごと削除されるため注意してください

### Q: タスクを追加できない

- 日付が正しい形式（YYYY-MM-DD）か確認してください
- マイルストーンは開始日と終了日が同日である必要があります

### Q: CSV インポートで依存関係が設定されない

- CSV の dependencies 列は **行インデックス（0始まり）** で記録されます
- 手動で CSV を編集する場合は、0行目のタスクを参照するなら `0`、1行目なら `1` を記入してください

### Q: 一括インポートで「Not a bulk export file」エラーが出る

- `version: "2.0"` の bulk_export 形式のファイルを使用してください
- 単一プロジェクトの JSON ファイルは Top 画面の Import ボタンから読み込んでください

### Q: 印刷プレビューがガントチャートのみにならない

- ブラウザのズームを 100% に設定してから印刷してください
- 「背景グラフィック」を印刷に含める設定をオンにしてください（色が正しく表示されます）

### Q: 今日ラインが表示されない

- 今日の日付がチャートの表示範囲内にある場合のみ表示されます
- タスクの日程が今日から大きく離れている場合は表示されません
- Global Config の「今日に自動スクロール」をオンにして今日位置に移動させてください

## 8. キーボードショートカット

スケジュール画面で使えるキーボードショートカットです。

| キー | 動作 |
|------|------|
| `N` | 新規タスク追加モーダルを開く |
| `Escape` | 開いているパネル / モーダルを閉じる |
| `Ctrl + F` | タスク検索フィールドにフォーカス |
| `Ctrl + P` | 印刷ダイアログを開く |
| `?` | このマニュアルを開く / 閉じる |

> **注意:** テキスト入力中（タスク名・メモ等）はショートカットが無効になります。`Escape` のみ常時有効です。
